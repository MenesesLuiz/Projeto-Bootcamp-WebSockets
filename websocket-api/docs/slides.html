As alternativas

Quatro jeitos de resolver isso

Polling

Cliente pergunta de novo a cada X segundos, sempre.

Long polling

Servidor segura a resposta até ter algo novo pra contar.

SSE

Servidor manda quando quiser — só nesse sentido.

WebSocket

Canal aberto: os dois lados mandam quando quiserem.
